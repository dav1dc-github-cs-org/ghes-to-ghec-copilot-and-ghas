# Training data (development)

Sample scenarios and attachments for running the instructor station locally
(`scripts/run-ios-local.sh`). Training centres keep their own library on the IOS host; this
directory mirrors its layout.

| Directory | Contents |
|---|---|
| `scenarios/` | One `<id>.yaml` file per scenario |
| `attachments/` | Approach charts, briefing notes and weather sheets referenced by scenarios |

Everything here is fictional: the FS-200 is a generic regional jet and XFSA and XFSB are not real
airports.
